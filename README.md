# What's for dinner? 🍽️

## A personal project for fun

A website for my family to save our favorite recipes and plan weekly meals.

## Features

- 📅 Weekly meal planning
- 📝 Recipe collection
- 🖼️ Recipe images
- 📱 Responsive design

## Project Status

This is the initial static HTML version. The full project plan includes building a React application with Supabase backend, meal planning features, and data engineering tools. See `meal-planner-project-plan.md` for the complete roadmap.

## Getting Started

Simply open `index.html` in your web browser to view the site locally.
